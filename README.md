# SpecPrawnik — koncepcja nowej strony głównej

Publiczny prototyp redesignu strony głównej. Wyszukiwanie, profile prawników i pozostałe działania prowadzą do aktualnego serwisu SpecPrawnik.

Strona jest statyczna (`index.html`, `styles.css`, `main.js`). Projekt Vercel wdraża ją bez kroku budowania.

Podgląd jest dostępny publicznie, ale zawiera dyrektywy `noindex` w HTML i nagłówkach HTTP. Nie jest to mechanizm kontroli dostępu.
